# BCDSS poster QR codes

A small browser tool for making QR codes for Bonn Center for Dependency and Slavery Studies (BCDSS) posters: Uni Bonn blue, a choice of module styles, and the BCDSS chain mark in the centre.

## Use

1. Paste the link the poster should point to.
2. Choose the centre mark and the style.
3. Download the SVG for print, or the PNG (2400 × 2400 px) for screens and quick layouts.

The page shows the minimum print width for each code. For posters read from about a metre away, print the code at 10 cm or more.

## Notes

- Everything runs in the browser. Links are not sent anywhere.
- Codes use error correction level H, so the centre mark does not affect scanning.
- The QR library ([qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator), MIT licence) loads from jsDelivr.
